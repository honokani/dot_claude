# SVMカーネル法の幾何学的直感と CNN へのスケール移行

機械学習で「なぜ SVM が大規模データで CNN に敗れたのか」を、カーネル法の数理構造を幾何学的に理解する形でまとめたメモ。

## カーネルトリックの本質

- 高次元特徴空間 φ(x) への明示的写像を計算せず、内積 `K(x, y) = <φ(x), φ(y)>` を直接計算する工夫
- 例: RBF `exp(-||x-y||²/σ²)` は φ が**無限次元**、明示的には書けない
- **1ペアの内積計算を効率化**しているだけで、全体の計算量 O(N²) は別問題

## カーネル ≡ グリーン関数との関連

- カーネル関数もグリーン関数も「2点の関係を表す関数」(two-point function)
- RKHS (再生核ヒルベルト空間) 理論で両者が繋がる
- RBFカーネル ⇔ 熱方程式のグリーン関数（同じガウス形式）
- Thin-plate spline カーネル ⇔ biharmonic 方程式のグリーン関数

## カーネル選択の自由度

- **Mercer条件 (正定値性)** を満たせば任意の関数をカーネルにできる
- Gaussian RBF が多用されるのは経験則 + 万能近似性 + 解析的便利さ
- Laplacian kernel `exp(-||x-y||₁/σ)` (マンハッタン距離ベース) も PSD で有効
- `1/(1+d(x,y))` や `exp(-d)` など多様なカーネル構築可能
- 計算量は大体 O(D) で同等、最適化との相性で差がつく

## ガウスRBFの幾何学的直感

- 各訓練サンプルが「位置に置かれたガウス山/谷」として影響場を作る
- 決定関数 `f(x) = Σ αi yi K(xi, x) + b` は山(y=+1)と谷(y=-1)の合成 landscape
- SVMは `f(x) = 0` の等高線（山谷の稜線）を決定境界にする
- 元空間で曲線、高次元特徴空間では超平面（線形分離）

関連アルゴリズム:
- **KDE**: 各点にガウス山置いて密度推定
- **Mean Shift**: 勾配に沿ってモード (山頂) に収束
- **Gaussian Process**: ガウス山の合成で回帰 + 不確実性評価

## 非線形SVMの原理: 次元拡張

- 元空間で非線形 ⇔ 高次元で線形
- XOR: 2D で分離不可能 → φ(x)=(x1, x2, x1·x2) で3次元化 → 平面で分離可能 → 元空間では双曲線
- 同心円: `φ(x) = ||x||²` で3次元目追加 → 1閾値で分離 → 元空間では円
- RBFカーネルは無限次元埋め込みで、元空間のあらゆる曲面境界を表現可能

## N²スケーラビリティ問題

**なぜ Gram行列 O(N²) から逃げられないか**:

1. 双対形式 `max Σαi - (1/2)Σij αi αj yi yj K(xi, xj)`
2. 制約 `Σαi yi = 0` + `0 ≤ αi ≤ C`
3. αi 同士が Gram 行列で結合 → 完全独立化不可能
4. 遠方の点も微量の寄与がある (`exp(-large²)` は極小だが非零)

**ニュートン法を使っても本質は同じ**:
- 反復は「逐次」だが各反復が O(N²) (全体を評価)
- SGD のような「ミニバッチで軽く更新」が使えない

## 近似手法 (スケール問題への対応)

| 手法 | アイデア | 計算量 |
|---|---|---|
| **Sparse Kernel / Cut-off** | 距離閾値以上を0扱い、Gram行列を疎化 | O(Nk) |
| **Compactly Supported Kernels** | Wendland 等、真にコンパクトサポート | 疎 |
| **Nyström 法** | ランダムなm個のランドマークで低ランク近似 | O(Nm + m³) |
| **Random Fourier Features (RFF)** | Bochner の定理でランダム周波数サンプリング → 明示低次元特徴 | O(ND) |
| **Fast Gauss Transform (IFGT)** | 多極展開（N体問題のBarnes-Hut 類推） | O(N log N) |
| **Cascade SVM** | ランダム分割で各chunk学習、サポートベクトル集約 | 並列効果 |
| **Spatial Partitioning** | 近傍クラスタ分割、局所SVM | 近傍限定 |

これらは「遠方の寄与は微小だから近似/切り上げ可能」というテイラー展開的発想で実装される。

## SVM vs CNN の本質的分岐

**問題の結び目はデータではなく解法構造にある**

| | SVM (カーネル) | CNN |
|---|---|---|
| 問題の凸性 | **凸** (グローバル最適解一意) | **非凸** (局所最適で十分) |
| 求めるもの | 厳密な最適マージン | 「いい感じの」局所最適 |
| 最適化手法 | QP (SMO, 内点法) | SGD + mini-batch |
| 1ステップの評価対象 | 全データ間の結合 | ミニバッチのみ (数十枚) |
| 独立化 | ✗ 全点結合必須 | ✓ 統計的近似で分散可 |
| 正確性 | グローバル最適解を厳密に | 近似解でOK |

**CNNが独立化できる理由 (確率的勾配の魔法)**:
```
真勾配  = (1/N) Σ_i ∇L_i       ← 全N必要
ミニバッチ勾配 = (1/B) Σ ∇L_i  ← Bだけで「期待値として」真勾配を近似
```
大数の法則でノイジーな勾配を平均すると真勾配に収束 → mini-batch 独立でOK。

**SVMで SGD が使えない理由**:
- 大域制約 `Σαi yi = 0` を一部更新では満たせない
- αi αj K(xi, xj) の全ペア結合が本質的

## 結論: 機械学習史の分水嶺

2010年代の ML は**「精度追求」から「スケール追求」へ**シフト。
- SVM = 凸最適化の厳密解 → N²の結び目
- CNN = 非凸最適化の近似解 + SGD → スケール自由
- GPU 並列化は後者にマッチ

同じ分類問題でも**定式化 (凸 vs 非凸) と最適化アプローチ (厳密 vs 確率的)** の違いで、計算コストの天地が分かれる。これが「アプローチ自体に結び目があった」の正体。

## 関連: Gaussian Process も同じ構造

- GP 回帰の厳密解は O(N³) (共分散行列)
- Sparse GP / Inducing Points / SVI で CNN と似た SGD 戦略へ
- 「凸 + 厳密解」の手法は同じ N² の壁を持つ

## 付録: 量子コンピュータで SVM 復活の可能性

もし計算コストが実質ゼロになる未来技術（fault-tolerant 量子コンピュータ等）が実現すれば、**凸最適化の厳密解を求める SVM アプローチが再評価される可能性**がある。

### 既存の量子SVM理論

- **Rebentrost, Mohseni, Lloyd (2014) "Quantum SVM"**: HHLアルゴリズム (Harrow-Hassidim-Lloyd, 2009) で Gram行列の逆計算を **O(log N)** に指数加速、理論上 SVM 学習が N²の壁を突破
- **Quantum Kernel Methods** (Havlíček et al. 2019, Nature): 量子回路で古典的に計算困難なカーネル関数を実装

### 現実の壁

- **QRAM** (Quantum RAM) が必要。理論的存在、実装困難
- **データロード**に O(ND) 必要 → 量子優位性を食い潰す
- **Aaronson の批判**: HHL は sparse + well-conditioned + simple readout の条件下で加速。現実データはこの条件を満たさないことが多い
- **NISQ時代**: 現行量子コンピュータはノイズ高く大規模実用不可
- **Fault-tolerant 量子** は 2040年代予想

### CNN も同時に量子加速される

- **Quantum Neural Networks (QNN)** や **Variational Quantum Circuits** も研究中
- 量子で SVM が速くなる ≠ SVM が CNN より速くなる
- ただし **凸最適化 (QP)** は量子が特に得意 (QAOA, 量子アニーリング) → 相対的に SVM 有利の可能性

### 復活シナリオ

| 用途 | SVM復活の見込み |
|---|---|
| 量子データの分類 (量子化学、材料) | 高 |
| 中規模タブラーデータ (〜数百万) | 中 |
| 画像・大規模汎用データ | 低 (CNN優位のまま) |

### 他の未来技術

- **Neuromorphic computing** (スパイキングNN、低消費電力)
- **In-memory computing** (メモリ内行列演算)
- **Photonic computing** (光で内積計算超高速)
- **アナログ計算** (物理的に行列-ベクトル積)

これらも **Gram行列処理を加速する可能性**があり、ハードウェア側からの SVM復活の目はある。

### 哲学的観点

現代ML の「近似解路線 (CNN+SGD)」は**計算コストの現実的制約の産物**。計算が「タダ」になれば：

- 凸最適の**厳密解**（ロバスト、解釈可能、理論保証あり）が本来望ましい
- SVM系（カーネル法、GP）の**数学的に美しい保証**が効いてくる
- ハードウェア進化で「どの解法が最適か」は変わる

機械学習は「問題 × 解法 × 計算資源」の三者関係。CNN 優位は 2010〜2020年代の GPU 時代の産物で、次世代ハードウェアでは**再逆転の可能性もゼロではない**、というのが歴史的視点での回答。

## 付録2: データが十分あれば手法選択は意味を失うか？

**「同じデータが十分揃っていたら SVM も CNN も同じ結果に収束するのでは?」という問いへの考察。**

### 理論面: 極限では収束する

**Universal Approximation Theorem**:
- RBF SVM: N→∞ で RKHS 内の任意連続関数を表現可能
- Neural Network (Cybenko 1989): 1隠れ層 + 十分なニューロンで任意連続関数近似
- **表現能力は両者同等**

**統計的一貫性 (Statistical Consistency)**:
- 両手法とも条件下で真の Bayes 最適分類器に収束
- N→∞ で**両者同じ関数に収束**するケースが多い

→ 理論極限では「同じ結果」はユーザーの直感通り**正しい**。

### しかし現実: 帰納バイアスが決定的

**帰納バイアス (inductive bias)** = 手法が持つ「データ構造に関する仮定」：

| 手法 | 帰納バイアス |
|---|---|
| RBF SVM | マージン最大化、滑らかな境界 |
| CNN | 局所性、平行移動不変性、階層特徴 |
| Transformer | 任意位置依存性 (attention) |
| GBDT | 階段状の境界、特徴重要度 |

**有限データでは「データ構造に合ったバイアス」が優位**：
- 画像 → CNN の局所性バイアス
- テキスト → Transformer
- タブラー → GBDT / SVM

### No Free Lunch Theorem (Wolpert 1996)

> 全タスクを平均すると、任意の2アルゴリズムの性能は同じ

→ 「万能最強アルゴリズム」は存在しない。**問題依存で最適手法は変わる**。

### 特徴表現 (Representation Learning) の差

```
SVM:  [生データ] → [手動設計特徴 or カーネル] → [分類]
CNN:  [生データ] → [自動で階層特徴学習] → [分類]
```

- SVM は**特徴設計が人間の仕事** (HOG, SIFT等)
- CNN は**特徴も end-to-end で学習**
- N→∞ で同じになるのは「特徴空間が同一の場合」。違う特徴空間なら違う関数に収束

### 極端ケース: 無限データ + 無限計算

- **両者ほぼ同じ結果** → 手法選択が理論的に意味を失う
- ただし**学習時間・メモリ・解釈性**の差は残る
- 最終選択は**非機能要件** (解釈性、信頼性、デプロイ性) に依存

### 現実の制約: データ量は無限にならない

- 収集コスト、labelingコストで**データは常に有限**
- サンプル効率の良い手法 (適切なバイアスを持つ手法) が勝つ
- 手法選択の価値は**現実世界では常に残る**

### 「手法選択の意味」早見表

| 観点 | 手法選択の意味 |
|---|---|
| 理論 (N→∞, 計算∞) | **消える** (両者 Bayes 最適に収束) |
| 実用 (有限 N, 有限計算) | **残る** (帰納バイアス、sample efficiency) |
| 非機能要件 (解釈性、信頼性、デプロイ) | **必ず残る** |
| タスク依存性 (NFL) | **必ず残る** |

### 哲学的見方

機械学習の本質は**「データから関数を学ぶ」**。

- 無限サンプル理論: 両手法同じ関数に収束 (Bayes最適)
- 有限サンプル現実: どの関数に近づくかは**バイアス次第**
- **「限られた時間で Bayes最適にどこまで近づけるか」** が実用評価軸

**データ量と計算資源の制約が手法の個性を際立たせている**、という視点。理論的には均等、実用的には必須選択 — 機械学習の微妙な立ち位置。
