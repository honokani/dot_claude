# blog-crawler

はてなブログ記事をクロールしてMarkdownファイルとして保存するスキル。

## 呼び出し方
```
/blog-crawler [N]
```
- N: クロールする記事数（デフォルト: 3）

## ワークフロー

### 1. URL_LIST.md を読む
- パス: `./blog_articles/URL_LIST.md`（カレントプロジェクトの相対パス）
- 状態が `pending` の行を上から N 件取得

### 2. 各記事をクロール（並列可）
- WebFetch で各URLを取得
- プロンプト: 「この記事の本文をMarkdown形式で全文抽出してください。タイトル、本文、数式をすべて含めてください。サイドバーやナビゲーション等は除外。可能な限り原文のまま返してください。」

### 3. Markdownファイルとして保存
- 保存先: `./blog_articles/{番号3桁}_{slug}.md`
- slug: タイトルからASCII安全な短縮名を生成（英数字・アンダースコアのみ、30文字以内）
- ファイル先頭にメタ情報ヘッダを付与:
  ```markdown
  # {タイトル}

  - 出典: {URL}
  - 参照元: {出典index}

  ---

  {本文}
  ```

### 4. URL_LIST.md を更新
- 各行の状態を `done: {ファイル名}` に変更

### 5. 完了報告
- クロールした記事数とファイル名を報告

## 注意事項
- WebFetchが失敗した場合: 状態を `error` にして次へ進む。エラー内容をユーザーに報告
- 長文記事でWebFetchが要約してしまう場合: その旨を状態に `partial` と記録し、ユーザーに報告
- 数式が多い記事はWebFetchの要約で欠落しやすいので、数式の有無を確認する
- 1セッションで大量にクロールしない（3〜5件程度が目安）
